# SQL Basic Queries

This repository contains a collection of simple and foundational SQL queries designed to help you learn, practice, and master the basics of SQL. Whether you're a student, developer, or data enthusiast, these queries will strengthen your understanding of database manipulation and retrieval.

## What's Included:
- Basic `SELECT` queries
- Filtering with `WHERE`
- Sorting with `ORDER BY`
- Grouping data with `GROUP BY` and `HAVING`
- Table joins (`INNER JOIN`, `LEFT JOIN`, etc.)

## Getting Started:
1. Clone the repository.
2. Open the `.sql` file in your favorite SQL client.
3. Execute the queries against your test database.
